 InerG – Software Testing Task

This repository contains the testing work completed as part of the second-round selection process for the Software Tester position at InerG.

The work covers manual testing activities along with additional Playwright automation.

Testing Activities

 01. UI Validation
- Checked the appearance and alignment of UI elements.
- Verified text, buttons, input fields and other visible components.
- Checked consistency of the UI against the expected behavior.

 02. Cross-Browser Testing
Testing was performed using:
- Google Chrome
- Microsoft Edge
- Mozilla Firefox

Both UI-related and negative test scenarios were covered.

 03. Negative Testing
- Tested invalid inputs and incorrect user actions.
- Checked validation and error handling.
- Covered boundary and unexpected input scenarios where applicable.

 04. Exploratory Testing
Exploratory testing was performed to identify unexpected behavior, usability issues and possible defects outside the predefined test cases.

 05. Bug Reporting
Identified issues were documented with relevant details such as:
- Bug ID
- Bug title
- Steps to reproduce
- Expected result
- Actual result
- Severity
- Priority
- Supporting evidence/screenshots where applicable

 06. Test Case Prioritization
Test cases were prioritized based on factors such as:
- Business impact
- Risk
- Functionality importance
- User impact

 07. Test Data Preparation
Prepared test data required for different testing scenarios, including valid, invalid and boundary data where applicable.

 08. Playwright Automation
Selected test scenarios were automated using Playwright.
